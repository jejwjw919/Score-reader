Score Reader 모바일 (웹앱) — 리듬게임 Arcaea 결과 화면 스크린샷 읽기 (비공식 팬 도구)
=================================================================================

※ lowiro 및 Arcaea 공식과 관계없는 개인 제작 무료 도구입니다.
※ 게임 이미지·음악·로고·곡 데이터를 포함하지 않습니다. 글자 모양·기준 글자·상수표는 사용자가 직접 등록합니다.
※ 사진은 폰 브라우저 안에서만 처리되고 어디로도 보내지 않습니다 (서버가 필요 없음).

폴더 구성
  index.html, app.js, reader.js   앱
  vendor/opencv.js                 이미지 처리 라이브러리 (OpenCV 4.10, Apache 2.0)
  sw.js, manifest.webmanifest, icons/   오프라인 사용·홈 화면 추가용
  tools/pc_export.py               PC 프로그램의 학습 데이터 -> 웹앱 백업 파일로 변환
  tools/parity.html                개발용 테스트 페이지 (배포할 때는 빼도 됨)

폰에서 쓰려면 (이 폴더를 HTTPS 주소로 올리기)
  홈 화면 추가와 오프라인 사용은 https 주소에서만 됩니다. 무료로 올리는 방법 예:
  - Netlify Drop (app.netlify.com/drop): 이 폴더를 끌어다 놓으면 주소가 생깁니다.
  - GitHub Pages: 저장소에 올리고 Pages 를 켭니다.
  주소를 폰 브라우저(아이폰 Safari / 안드로이드 Chrome)로 열고
  - 아이폰: 공유 → 홈 화면에 추가
  - 안드로이드: 메뉴 → 홈 화면에 추가(앱 설치)
  처음 한 번 열 때 약 10MB를 받고, 그다음부터는 인터넷 없이도 열립니다.
  ※ 공개 주소에 올리기 전에 lowiro 답장을 먼저 받는 것을 권합니다.

처음 한 번: [설정] 탭
  1. 기준 글자 등록: 결과 화면 스크린샷 한 장에서 HIGH SCORE, MAX RECALL 글자를 손가락으로 끌어서 감싸고 "이대로 등록"
  2. 글자 모양 학습: [학습] 탭에서 스크린샷을 고르고 화면을 보며 값을 입력해 "등록" (0~9가 골고루 나오게 5~10장)
  3. 상수표: [상수표] 탭에서 표를 붙여넣거나 한 곡씩 추가
  PC 프로그램을 이미 쓰고 있다면, PC에서
      python tools\pc_export.py
  를 실행해 만든 score_reader_backup.json 을 폰으로 옮긴 뒤 [설정 → 백업 가져오기]로 넣으면 1~3이 한 번에 끝납니다.
  (학습한 글자 모양, 기준 글자, 자켓 기억, 상수표, 저장표의 내 기록까지)

[읽기]   스크린샷 여러 장을 골라 한 번에 읽기. 통과(OK)한 점수는 내 기록에 저장(더 높을 때만). CSV 내보내기.
[학습]   인식 결과를 고쳐서 등록. 상수표에 없는 곡이면 "상수표에 추가".
[상수표] 검색·추가·삭제, 표 붙여넣기로 새로 만들기, 내 점수 보기.
[기록]   곡 / 난이도 / 점수 / 포텐셜 (높은 순), CSV 내보내기, 모든 기록 초기화.
[설정]   설정 상태, 기준 글자 등록, 백업 내보내기/가져오기, 모든 데이터 지우기.

데이터는 그 기기의 브라우저 저장소(IndexedDB)에 저장됩니다. 브라우저 데이터를 지우면 사라지니 가끔 [백업 내보내기]를 해 두세요.
